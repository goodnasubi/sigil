# Sigil

**AI が書き、AI が読み、人間が検証するための開発言語。**

Sigil（シジル）は、AI による記述・生成・検証を前提に設計する実験的なプログラミング言語です。
人間にとって読みやすいことよりも、AI が意図を曖昧さなく表現し、機械的に検証できることを優先します。

> **ステータス:** 設計段階（構想・文書化）。実装はまだありません。

## 動機

- 既存の言語は人間の書き手を想定しており、AI が生成したコードの意図や前提が暗黙になりやすい。
- AI が生成した成果物を、型・契約・効果などの仕組みで機械的に検証できる言語が必要。
- 「何をしたいか」（意図）と「どう実行するか」（実装）を分けて記述できると、AI 同士の協調や差分の検証がしやすくなる。

## 設計の柱（草案）

1. **意図の明示**: 関数や単位ごとに、目的・前提・事後条件を一級の構文として書けること。
2. **機械的検証**: 型・契約・効果の情報を使い、生成されたコードを実行前に検査できること。
3. **決定的な表現**: 同じ意味を複数の書き方で表せないこと（正規化可能な構文）。
4. **可読性より検証可能性**: 人間が読めることは重要だが、検証可能性を妥協しない。

詳細は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。
