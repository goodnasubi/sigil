# サーバーの時計

`targets server` の `trust none` アプリは、`effects clock` を宣言した関数から以下の時計を利用できる。

| API | 成功時の値 | 用途 |
|---|---|---|
| `clock.monotonic_nanos() -> Option<Int>` | Linux の `CLOCK_MONOTONIC` が返す、任意の起点からの整数ナノ秒 | 期限・処理時間・トークンバケットの補充間隔 |
| `clock.unix_seconds() -> Option<Int>` | UTC の Unix エポックからの整数秒 | ログや有効期限など、暦上の時刻との比較 |

単調時計は壁時計の時刻設定で逆行しない。連続した読み取りは同じ値を返すことがある。
同じ時計の読み取り値の差を経過時間として使う。起点は Unix エポックと異なり、
システムのサスペンド中は進まない。取得失敗や整数範囲外は `None` になる。

信頼基盤の `std.os.io.io_now()` は同じ OS 時計取得処理を共有する。
公開 API は評価器とネイティブの両方で実時間を読み、決定的なタスクスケジューラの仮想時計とは独立している。
